The three meters

What you are actually playing against

Cash, compute and exposure move independently, and a node can be stopped by any one of them. The status label tells you which.

Cash drains three ways at once

A one-off place cost, a monthly bill charged continuously, and per-craft API spend debited the moment a craft starts.

1 billing month = 300s of play · $25/mo ≈ 8¢ per game-second
  • Start with $2,000
  • Demolish refunds 50% of the place cost
  • Zero cash → node reads Out of cash and stops

Compute thousands of tokens / min

Every node draws it; only Capacity nodes supply it. Short of supply, everything runs at supply ÷ demand speed and reads throttled (429).

satisfaction = min(1, supply / demand) · draw = computeDraw × clock1.6
  • It degrades smoothly — it never cliffs
  • Capacity nodes are exempt, so they always run
  • Overclocking to 2× costs ≈3.0× the throughput

Exposure architectural, not behavioural

The sum of dataRisk across every enabled node that has a recipe assigned. Wiring a risky provider in exposes you whether or not it is mid-craft.

breach/min = 2.4 × (exposure / 100)²
  • Quadratic: 20 is nothing, 80 is fatal
  • A breach takes 12% of cash (min $500)
  • …and freezes every contract for 20s
  • Each contract also refuses to run above its own ceiling

The rule that catches everyone milestones

Milestone progress records contract inputs, not production. A thousand answers you never route to a customer advance nothing. Links carry 240 units/min and each node holds 400 units per slot, so a starved link and a backed-up buffer look identical until you read the status.

Opening

First five minutes

Opening moves you start with $2,000

  1. Place Free Tier first and give it the Free Tier recipe. Without capacity, satisfaction is 0 and every node reports 429 — which hides whatever is actually wrong.
  2. Place Landing Page → Organic Signups, GPT-5.6 Luna → Luna Draft, and Consumer App → Freemium Tier.
  3. Drag the User Request output dot to GPT-5.6 Luna, then its output dot to Consumer App. Colours must match.
  4. Sell 40 Draft Answer to clear First Users — $1,500 and 8 new nodes.

Known pacing quirk: one Landing Page makes 30/min and one GPT-5.6 Luna eats 48/min, so a single source starves a single model node. The starting kit draws 126k against 150k supplied — room for 0 more model node(s) before you need a bigger tier.

Four traps each costs a run

  • Placing a model before capacity. Everything reads 429 and you blame the model.
  • Producing without selling. Milestones read contract inputs only. Unsold output is a buffer, not progress.
  • Adding a cheap high-risk provider late. The per-craft saving is real; the +8 Exposure silently pushes you over an existing contract's ceiling and that contract quietly stops paying.
  • Overclocking. Draw scales as clock1.6, so 2× speed costs 3.0× the throughput. Usually cheaper to place a second node.
